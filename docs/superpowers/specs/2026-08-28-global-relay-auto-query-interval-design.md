# 全局中转站自动查询间隔设计

## 目标

在设置窗口中增加一个按分钟配置的自动查询间隔，并让它统一覆盖所有启用的中转站额度查询。该配置只影响中转站，不影响 Codex 官方额度查询。

## 配置与兼容性

- 设置 schema 从 2 升级到 3。
- 新增 `Relay.AutoQueryIntervalMinutes`，默认值为 `10`，允许范围为 `0..1440`。
- 值为 `0` 时关闭中转站自动查询，但手动刷新仍然会查询启用的中转站。
- 旧 schema 1 和 2 设置迁移到 schema 3；迁移不改写中转站注册表，也不删除每个中转站已有的 `IntervalMinutes`。
- 设置读取和写入继续使用现有的 canonical 校验、原子写入和损坏文件隔离机制。

## UI 与交互

- 设置窗口新增“自动查询间隔（分钟）”输入控件及对应的自动化名称。
- 打开设置时显示当前全局值。
- 用户输入合法整数后保存设置并立即更新调度器；输入为空、非整数或超出范围时不保存，并显示错误状态。
- 现有显示模式、主题、布局、置顶、开机启动、立即刷新和中转站管理行为保持不变。

## 运行时行为

- 调度器创建和全局间隔变更时，所有 provider entry 使用同一个有效 `IntervalMinutes`，该值来自 `Relay.AutoQueryIntervalMinutes`。
- 全局间隔大于 0 时，启用且未暂停的中转站按该间隔自动查询。
- 全局间隔为 0 时，自动调度不启动；手动刷新仍绕过间隔限制并遵循现有信任阻断规则。
- 现有并发上限、认证暂停、脚本错误暂停、限流重试、指数退避和 sidecar 生命周期处理不变。
- 修改间隔后重建调度状态，使新的值从下一轮调度起生效，不改变 provider 配置文件中的原始间隔。

## 测试

- 单元测试覆盖默认值、schema 迁移、范围和类型校验、canonical 持久化。
- 调度器测试覆盖全局值覆盖 provider 值、`0` 的手动模式和设置变更后的下一轮行为。
- 设置视图组合测试覆盖新控件和自动化名称。
- 设置控制器测试覆盖显示、合法保存、非法输入拒绝和错误状态。
- 运行完整 PowerShell 单元与集成测试集。
