# Codex 额度监控快捷方式图标设计

日期：2026-08-01
状态：视觉方案已确认，等待书面设计复核

## 1. 目标

为 Codex 额度监控制作两套原创 Windows 图标：纯白色系和白蓝色系。两套图标均保留在项目中，用户选定的白蓝色系作为桌面快捷方式的默认图标。

本次只改变快捷方式的视觉图标，不改变程序、启动方式、快捷方式目标、参数或开机启动行为。

## 2. 视觉语言

两套图标采用相同的原创构图：白色圆角方形底板、环形额度仪表和简化终端符号。仪表表达“额度与剩余量”，终端符号表达“本地开发工具”。图形在小尺寸下必须保持粗线条和清晰留白。

可编辑源图使用 128 × 128 视图框，画布外缘透明且不加阴影。底板位于 `(5, 5)`，尺寸为 118 × 118，圆角半径 29；仪表圆心为 `(64, 64)`，半径 41；额度弧从圆顶开始，顺时针保留左下方约四分之一的缺口；终端符号由位于仪表中央的 `>` 折线和右下短横线组成。所有尺寸的位图都由同一源图渲染。

### 2.1 纯白色系

- 底板：白色 `#FFFFFF`；
- 外边框：浅灰 `#D7DDE5`，基准线宽 4 像素；
- 仪表底轨：浅灰 `#E7EBF0`，基准线宽 12 像素；
- 额度弧线：石板灰 `#64748B`；
- 终端符号：石墨色 `#1F2937`，基准线宽 7 像素。

### 2.2 白蓝色系

- 底板：白色 `#FFFFFF`；
- 外边框：浅蓝 `#BFDBFE`，基准线宽 4 像素；
- 仪表底轨：淡蓝 `#DBEAFE`，基准线宽 12 像素；
- 额度弧线：从 `#60A5FA` 到 `#2563EB` 的蓝色渐变，基准线宽 12 像素，圆形端点；
- 终端符号：深蓝 `#1E3A8A`，基准线宽 7 像素。

白蓝色系是桌面快捷方式的默认方案。

## 3. 品牌区分

图标不使用 OpenAI/Codex 官方花结图形、官方字标、官方字体或近似官方图标的轮廓。项目名称可以说明工具用途，但视觉上应保持为第三方原创额度仪表。若仓库日后公开，README 应明确说明这是非官方项目，且不暗示 OpenAI 的认可或合作。

以上是降低混淆风险的设计措施，不构成法律意见。

## 4. 交付文件

项目中保存四个可追踪文件：

- `assets/codex-quota-monitor-white.svg`；
- `assets/codex-quota-monitor-white-blue.svg`；
- `assets/codex-quota-monitor-white.ico`；
- `assets/codex-quota-monitor-white-blue.ico`。

每个 ICO 包含 16、24、32、48、64、128 和 256 像素的图像帧。SVG 作为可编辑源文件，ICO 用于 Windows 快捷方式。

安装后的白蓝图标复制到稳定位置：

`%LOCALAPPDATA%\CodexQuotaMonitor\assets\CodexQuotaMonitor.ico`

桌面快捷方式 `Codex 额度监控.lnk` 的 `IconLocation` 指向这个稳定文件。本次不修改开机启动快捷方式；其目标、参数和图标都保持不变。

## 5. 更新顺序与失败保护

1. 先生成两套 SVG 和多尺寸 ICO。
2. 检查 ICO 文件可读取且包含全部指定尺寸。
3. 将白蓝 ICO 复制到稳定安装目录。
4. 读取并保存桌面快捷方式现有的目标、参数和工作目录。
5. 仅修改快捷方式的 `IconLocation`。
6. 如果生成、读取或复制失败，不修改快捷方式，继续保留当前 PowerShell 图标。

## 6. 验证标准

- 两套 SVG 均能正常渲染，构图和配色符合本说明；
- 两个 ICO 均包含 16、24、32、48、64、128 和 256 像素帧；
- 白蓝图标在 16、32、48 和 256 像素下仍可辨认；
- 桌面快捷方式的目标、参数和工作目录在更新前后完全一致；
- `IconLocation` 指向存在且可读取的稳定 ICO 文件；
- 双击桌面快捷方式能够启动或唤起额度监控；
- 运行实时健康检查后，监控仍处于健康状态；
- 必要时刷新 Windows 图标缓存显示，但不得删除用户文件或重建整个图标缓存。

## 7. 非目标

- 不重新设计程序窗口或托盘动态图标；
- 不替换 OpenAI、Codex 或 PowerShell 的系统图标；
- 不修改额度读取逻辑、安装路径或自启动机制；
- 不在本次工作中公开仓库或更改仓库可见性。
