# 可控迷你额度、主界面刷新与双折叠自适应设计

**日期：** 2026-08-10  
**状态：** 已确认，等待书面规格复核

## 背景

额度监视器已有完整窗口、迷你条和额度球三种显示模式，也已有一个由
`Compact.FocusMetric` 保存的共用聚焦项。完整窗口中的官方额度和中转站额度卡片
都能触发聚焦，迷你条与额度球也会读取同一个聚焦结果。

当前体验仍有三个问题：

1. 迷你模式只显示额度项目自身的标签，来源不够明确；现有“聚焦此额度”文案也没有
   说明它控制迷你条和额度球。用户很难确认当前显示的是官方额度还是哪个中转站额度。
2. 托盘菜单已有“立即刷新”，但完整窗口没有刷新入口。
3. 完整窗口虽然使用 `SizeToContent="Height"`，却设置了 `MinHeight="240"`。官方和
   中转站两个分组同时折叠后，自然内容高度低于最小高度，窗口仍保留大片空白。

## 目标

- 让迷你条和额度球共用一个由用户明确选择的具体额度项。
- 允许官方额度或任意中转站额度作为该显示项，并在迷你模式中明确展示来源。
- 在完整窗口标题栏增加立即刷新按钮，复用现有刷新通道。
- 允许官方和中转站分组同时折叠，并让窗口随内容自动缩短和恢复。
- 保持现有设置、凭据、查询脚本和调度机制兼容。

## 非目标

- 不为迷你条和额度球分别保存不同的显示项。
- 不在迷你条或额度球内部增加下拉菜单或右键选择器。
- 不改变中转站提供方配置、凭据格式、查询协议或刷新周期。
- 不保存官方和中转站分组的展开状态。
- 不改变“标签页”完整窗口布局的行为。

## 用户体验

### 1. 在完整总览中选择迷你模式显示项

每张官方或中转站额度卡片保留一个圆点选择按钮。按钮未选中时显示空心圆，选中时
显示实心圆；提示文字和辅助功能名称由“聚焦此额度”改为：

- 未选中：`设为迷你模式显示项`
- 已选中：`取消迷你模式固定显示`

点击未选中按钮，将该卡片的稳定额度 Key 写入现有 `Compact.FocusMetric`。迷你条和
额度球立即共同显示该项。点击已选中按钮恢复 `Auto`，继续使用现有自动选择规则。

完整窗口仍是唯一的选择入口。点击迷你条或额度球主体会返回完整窗口，用户可在那里
更改选择。

### 2. 迷你模式明确显示来源

内部展示记录增加一个仅用于界面显示的 `SourceLabel`：

- 官方额度使用 `Codex 官方`；
- 中转站额度使用提供方名称，例如 `Wakaka`。

迷你条和额度球使用 `SourceLabel · Label` 作为项目说明，例如：

- `Codex 官方 · 5 小时额度`
- `Wakaka · 账户余额`

过长文本使用省略号截断，完整来源、项目名、值、新鲜度和重置时间仍保留在工具提示中。
`SourceLabel` 只属于运行时展示记录，不进入持久化设置，也不包含中转站 URL 或凭据。

### 3. 手动选择采用严格语义

`FocusMetric = Auto` 时，继续从可比较的官方和中转站记录中选择剩余比例最低的一项。

`FocusMetric` 为具体 Key 时，只允许返回该 Key 对应的可用记录。若该记录暂时缺失、
被禁用或当前数据无效，不得静默回退到另一条官方或中转站记录。两个迷你模式统一显示：

- 标签：`所选额度暂不可用`
- 数值：`—`
- 进度圆环或进度条：隐藏

设置中的原 Key 保持不变。该记录恢复后，迷你条和额度球自动恢复显示，无需重新选择。
用户主动取消固定，或所选中转站被永久删除时，才将设置恢复为 `Auto`。

### 4. 完整窗口刷新按钮

标题栏在“切换完整窗口布局”和“隐藏悬浮窗”之间增加 `RefreshButton`：

- 内容：`↻`
- 工具提示：`立即刷新`
- 辅助功能名称：`立即刷新官方和中转站额度`

点击按钮后：

1. 底部状态临时显示 `正在刷新…`；
2. 调用与托盘菜单相同的 `RequestRefresh` 脚本块；
3. 现有刷新事件同时唤醒官方额度查询和所有已启用中转站的手动刷新；
4. 连续点击由现有事件机制合并，不创建并行重复查询；
5. 下一次界面状态发布用实时或过期状态替换 `正在刷新…`。

刷新失败不弹出阻塞对话框，也不清空最近一次有效额度。现有过期状态与安全错误分类继续
负责展示失败结果。刷新路径不读取、记录或输出中转站凭据。

### 5. 两个分组同时折叠时自动适应高度

完整窗口继续使用 `SizeToContent="Height"`。将固定的 240 逻辑像素最小高度降低到
136 逻辑像素；如果标题栏、边距和两个分组头的自然高度更高，WPF 仍以自然高度为准。

官方额度和中转站额度允许同时折叠：

- 两者折叠后，窗口缩短到标题栏、两个分组头和必要边距的高度；
- 任一分组重新展开后，窗口按照内容自然增高；
- 内容超过既有滚动区域上限时，继续使用垂直滚动条；
- 高度变化不修改窗口 Left、Top、Topmost 或 Visible 设置。

不保存折叠后的瞬时高度，也不强制至少展开一个分组。标签页布局没有 Expander，因此
保持现状。

## 架构与事件流

### 展示记录

官方记录适配与中转站记录转换都提供 `SourceLabel`。复制、组合和测试辅助函数必须保留
该字段。它不改变额度 Key，也不参与排序、严重程度或缓存格式。

### 显示控制器

`DisplayModeController` 继续持有唯一的 `FocusKey`，并同时渲染完整窗口、迷你条和额度球。
选择流程为：

```text
完整窗口额度卡片
    → OnFocusRequested(Key)
    → DisplayModeController.SetFocusKey(Key | Auto)
    → 保存 Compact.FocusMetric
    → 严格选择对应展示记录
    → 同步渲染迷你条和额度球
```

`Get-CompactFocusRow` 在收到具体 `PinnedKey` 但找不到可用记录时返回空值，不再继续执行
自动候选排序。控制器把同一个 `PinnedKey` 传给两个迷你视图，使它们能区分“自动模式无
可比较记录”和“手动选择项暂不可用”。

### 刷新事件

`WpfView` 注册和释放 `RefreshButton` 点击处理器，并通过 `OnRefreshRequested` 回调暴露
刷新请求。运行时创建的同一个 `requestRefreshAction` 同时提供给标题栏按钮和托盘菜单，
确保两处行为一致。回调只设置既有刷新事件，不直接调用网络或中转站脚本。

### 窗口测量

双折叠修复依赖现有 WPF 自然测量，不引入第二套手工高度计算。降低 `MinHeight` 后，
Expander 的展开和折叠会触发布局重新测量，`SizeToContent` 据此调整窗口高度。

## 错误与生命周期处理

- 手动选择项暂不可用时保留 Key 并显示明确占位状态。
- 被永久删除的中转站如果拥有当前 FocusKey，删除成功后把 FocusMetric 重置为 `Auto`。
- 刷新请求失败时保留最近一次有效数据；官方或单个中转站失败不阻止其他来源更新。
- 新增的刷新按钮事件与现有额度选择按钮事件在视图释放时全部解绑。
- 释放后的窗口不得响应刷新、选择或折叠回调。
- 所有新工具提示和辅助功能名称使用中文，不暴露 URL、请求头或凭据。

## 测试策略

### 单元测试

- `Get-CompactFocusRow` 在 Auto 模式继续选择最低可比较比例。
- 具体 Key 能选择官方百分比、中转站百分比和中转站绝对余额。
- 具体 Key 缺失或不可用时返回空值，不回退到其他来源。
- `DisplayModeController` 将同一 Key 和选择状态传给迷你条与额度球并持久化一次。
- 删除当前选中的中转站后 FocusMetric 恢复为 `Auto`。
- 标题栏刷新和托盘刷新都只设置同一刷新请求通道；重复请求不会创建并行工作。

### WPF 集成测试

- `RefreshButton` 位于标题栏正确列，尺寸、工具提示和辅助功能名称有效。
- 点击刷新按钮恰好调用一次回调；释放后不再调用。
- 官方与中转站卡片使用新的选择文案和选中状态。
- 迷你条和额度球显示 `SourceLabel · Label`，并正确截断长文本。
- 手动选择项不可用时，两种迷你模式显示统一占位状态。
- 两个 Expander 同时折叠后测得高度小于展开状态且不低于自然内容高度。
- 任一 Expander 重新展开后高度恢复，滚动区域上限保持有效。

### 视觉与运行验收

视觉矩阵覆盖：

- Light / Dark；
- 100% / 150% 缩放；
- 官方额度固定到迷你模式；
- 中转站百分比固定到迷你模式；
- 中转站绝对余额固定到迷你模式；
- 手动选择项暂不可用；
- 两个分组同时折叠；
- 新标题栏刷新按钮。

完成后运行全部 Pester 测试，使用仓库安装脚本覆盖安装，再执行普通健康检查与状态检查。
验收标准是测试零失败、视觉矩阵无截断或重叠、已安装实例为 `Healthy=True`、
`Installed=True`、`Running=True`，且实际安装文件包含本设计的控件和行为。

## 已确认决策

- 迷你条和额度球共用一个选择。
- 选择精确到具体额度项。
- 只在完整额度总览中选择。
- 两个分组可同时折叠，窗口自动适应内容高度。
- 刷新按钮位于完整窗口标题栏。
