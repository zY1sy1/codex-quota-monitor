# 配额卡片圆形选择按钮视觉优化设计

## 1. 背景与问题

完整额度窗口中的每张配额卡片都有一个按钮，用于把该配额固定为迷你条和额度球的显示项。当前按钮直接使用字体字符 `○` 和 `●`，同时沿用 WPF `Button` 的系统默认控件模板。

这带来三个视觉问题：

- 字体圆点会随字体、抗锯齿和 DPI 缩放产生尺寸与居中差异；
- 透明背景和透明边框不会移除系统默认模板，焦点、悬停或按下时仍可能出现生硬的蓝色方框；
- 卡片描边与圆点虽然都表达选中，但按钮本身缺少完整、统一的交互状态。

## 2. 目标与非目标

### 目标

- 保留圆形单选语义，不改成图钉、书签或复选标记；
- 使用 WPF 矢量几何绘制圆环和圆点，保证 100% 与 150% 缩放下清晰、同心；
- 为未选中、悬停、按下、键盘焦点和已选中提供一致且克制的反馈；
- 在浅色和深色主题中保持足够对比度；
- 保留现有工具提示、辅助功能名称、键盘访问和点击逻辑。

### 非目标

- 不改变 `FocusKey`、`Compact.FocusMetric` 或自动选择规则；
- 不改变完整窗口、迷你条或额度球的布局和尺寸；
- 不改变卡片内容、进度条、刷新逻辑或数据模型；
- 不修改安装目录中的部署副本，安装仍通过现有脚本完成。

## 3. 视觉设计

采用已确认的“轻柔单选”方案。

### 3.1 尺寸与几何

- 按钮点击区域保持 `28 x 28`，与现有头部图标按钮的最小交互尺寸一致；
- 按钮内部使用 `24 x 24` 的圆形状态表面；
- 未选中图标为 `16 x 16` 圆环，描边 `1.5`；
- 已选中时在圆环中心显示直径 `6` 的实心圆点；
- 图标与按钮表面水平、垂直居中，继续使用与额度值之间的现有 `6` 像素间距。

圆环与中心圆点都使用 WPF `Ellipse`，不再依赖字体字符。

### 3.2 状态

| 状态 | 圆环与圆点 | 圆形按钮表面 | 卡片 |
| --- | --- | --- | --- |
| 未选中 | 次要文字色圆环，无圆点 | 透明 | 原有表面与分隔线 |
| 悬停 | 强调色圆环，圆点保持当前选择状态 | 低透明度强调色 | 不变 |
| 按下 | 强调色圆环，圆点保持当前选择状态 | 比悬停略强的强调色 | 不变 |
| 已选中 | 强调色圆环与 `6` 像素圆点 | 低透明度强调色 | `1` 像素强调色描边和极轻的强调色倾向 |
| 键盘焦点 | 保留当前选择图形 | `24 x 24` 圆形柔和焦点环 | 不变 |

键盘焦点是独立的可访问状态，不使用系统默认矩形焦点框，也不与中心圆点混淆。鼠标悬停、按下和键盘焦点均不得改变按钮或卡片的布局尺寸。

### 3.3 主题

现有 `Accent`、`TextSecondary`、`SurfaceStrong` 和 `Separator` 继续作为基础颜色。主题调色板增加仅供选择状态使用的柔和强调表面和选中卡片表面，分别为浅色与深色主题提供固定、可测试的 ARGB 值。

颜色只辅助表达状态。圆环、中心圆点和卡片描边共同确保用户无需仅依赖颜色判断是否选中。

## 4. 实现边界

### `companion/UI/MainWindow.xaml`

增加专用于配额选择按钮的样式和控件模板：

- 模板根元素是固定 `24 x 24` 的圆形表面；
- `ContentPresenter` 承载矢量圆环内容；
- 模板负责悬停、按下和圆形键盘焦点反馈；
- 模板完全替代系统默认按钮外观，避免矩形系统高亮重新出现。

### `companion/Private/WpfView.ps1`

`New-WpfQuotaCard` 继续创建按钮、工具提示、辅助功能名称和点击回调，但按钮内容改为由两个同心 `Ellipse` 组成的矢量视觉：

- 外层圆环始终存在；
- 中心圆点只在 `$selected` 为真时显示；
- 颜色、按钮表面和卡片表面从当前主题调色板取得；
- 重绘仍沿用现有快照渲染流程，不新增持久状态或事件订阅。

### `companion/Private/Theme.ps1`

为浅色和深色主题提供柔和按钮选择表面与选中卡片表面颜色。现有公共主题行为和其他按钮颜色不变。

## 5. 交互与辅助功能

- 点击未选中按钮仍把该卡片的稳定 Key 设为迷你模式显示项；
- 点击已选中按钮仍恢复 `Auto`；
- 按钮继续可聚焦并支持键盘激活；
- 未选中工具提示保持 `设为迷你模式显示项`；
- 已选中工具提示保持 `取消迷你模式固定显示`；
- `AutomationProperties.Name` 继续与当前工具提示一致；
- 按钮的 28 像素点击区域不因图标缩小而缩小。

## 6. 测试策略

按测试驱动方式实施：

1. 先扩展 WPF 组合测试，要求选择按钮使用矢量内容而不是字符串，并断言圆环、圆点、尺寸和选中可见性；
2. 增加模板合同测试，验证按钮应用专用模板且不再使用默认矩形边框；
3. 覆盖未选中与已选中的卡片描边、背景、工具提示、辅助功能名称和点击回调；
4. 覆盖浅色和深色调色板的新选择状态颜色；
5. 运行相关 WPF 与主题集成测试，再运行完整 PowerShell 测试套件；
6. 使用现有视觉矩阵检查浅色、深色、100% 和 150% 缩放下的完整窗口；
7. 安装到本地后运行健康检查，确认运行实例加载新界面且交互逻辑未回归。

## 7. 验收标准

1. 配额选择按钮不再显示字体 `○` 或 `●`；
2. 未选中与已选中图标均为清晰、同心的圆形矢量；
3. 任何交互状态下都不出现系统默认蓝色方框；
4. 已选中状态清晰但不过重，卡片尺寸和内容位置不发生跳动；
5. 键盘用户仍能明确看到圆形焦点反馈并完成选择；
6. 浅色、深色、100% 和 150% 缩放下均无模糊、裁切或错位；
7. 迷你模式选择、取消选择、工具提示和辅助功能行为保持兼容。

## 8. 风险控制

| 风险 | 控制措施 |
| --- | --- |
| 自定义模板移除默认焦点后影响键盘可用性 | 同时提供专用圆形焦点视觉并增加测试与人工检查 |
| 选中反馈过强，抢占额度值层级 | 使用细描边、低透明度表面和小中心圆点 |
| 半透明颜色在不同主题中对比不足 | 为浅色和深色主题分别定义并测试颜色值 |
| 矢量内容改变按钮测量结果 | 固定点击区域、状态表面和图标尺寸，状态切换只改变颜色与可见性 |
| 修改覆盖当前工作树中的其他调整 | 仅在相关局部增量编辑，并保留现有未提交修改 |
