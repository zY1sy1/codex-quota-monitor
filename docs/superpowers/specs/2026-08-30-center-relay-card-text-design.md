# 中转站卡片文字垂直居中设计

## 1. 背景与问题

完整额度窗口使用同一套程序化 WPF 卡片结构展示官方额度和中转站额度。中转站卡片的更新时间可能包含多行文字，而同一行左侧的倒计时或占位符通常只有一行。文本控件沿用默认的垂直拉伸行为时，短文本会贴近所在行顶部，看起来没有与右侧多行信息垂直对齐。

本次修改只处理用户已确认的中转站卡片内部文字垂直对齐。卡片本身仍按现有顺序排列，不在中转站区域内增加额外留白或重新定位。

## 2. 目标与非目标

### 目标

- 让中转站卡片内的标题、额度值、辅助说明、倒计时和更新时间文本在各自布局行内垂直居中；
- 保持现有水平对齐，其中标题和额度值仍按当前方向排列，更新时间仍右对齐；
- 保持官方额度卡片的现有布局行为；
- 在多行辅助说明或更新时间出现时，让同一行中的短文本保持视觉居中。

### 非目标

- 不让整张中转站卡片在列表区域内垂直居中；
- 不改变卡片高度、宽度、内边距、外边距、圆角或排列顺序；
- 不改变官方额度卡片、进度条、选择按钮、主题或窗口布局；
- 不改变额度数据、刷新调度、状态计算或持久化逻辑；
- 不修改安装目录中的部署输出。

## 3. 方案选择

采用在 `New-WpfQuotaCard` 中按 `SourceKind = Relay` 精确处理文本控件的方案。

创建卡片时读取展示行的 `SourceKind`。仅当来源为 `Relay` 时，把以下现有 `TextBlock` 的 `VerticalAlignment` 设为 `Center`：

- `QuotaLabel`；
- `QuotaRemaining`；
- `QuotaSecondary`；
- `QuotaCountdown`；
- `QuotaResetTime`。

不使用卡片级隐式 `TextBlock` 样式，以免影响选择按钮或未来加入的嵌套文本；也不统一修改官方与中转站卡片，因为用户已明确要求官方卡片保持现状。

## 4. 实现边界

### `companion/Private/WpfView.ps1`

- 在 `New-WpfQuotaCard` 中从展示行读取一次 `SourceKind`；
- 卡片的所有现有控件创建完成后，仅对中转站卡片的五个文本控件应用垂直居中；
- 不改变这些控件的 `TextAlignment`、`Margin`、`TextWrapping`、字体、颜色或可见性；
- 不新增公共函数、持久状态、事件处理器或数据字段。

### `tests/Integration/WpfComposition.Tests.ps1`

- 同时渲染一张官方额度卡片和一张包含多行文本的中转站卡片；
- 断言中转站卡片的五个目标文本控件均为 `VerticalAlignment.Center`；
- 断言关键水平对齐保持不变；
- 断言官方额度卡片未被中转站条件分支改变。

## 5. 数据流与错误处理

本次修改不改变数据流。`PresentationRow` 仍由现有展示层生成，`New-WpfQuotaCard` 只读取已有的 `SourceKind` 并设置视图属性。

现有来源值的处理规则保持不变：只有严格等于 `Relay` 的行采用该视觉调整，缺失值、未知值和 `Official` 均沿用当前布局。因此不引入新的异常路径或用户可见错误状态。

## 6. 测试与验证

按测试驱动方式完成并验证：

1. 先运行新增的 WPF 组合测试，确认它会因中转站目标文本尚未全部垂直居中而失败；
2. 应用最小视图修改后重新运行该测试，确认通过；
3. 运行完整的 WPF 组合测试，确认其他卡片布局与交互未回归；
4. 运行相关 PowerShell 测试套件；
5. 使用现有视觉捕获流程检查深色和浅色主题下的中转站卡片，重点比较单行倒计时与多行更新时间的行内位置；
6. 保持官方额度卡片作为视觉与自动化回归对照。

## 7. 验收标准

1. 中转站卡片的五个目标文本控件在各自布局行内垂直居中；
2. 单行倒计时或占位符与同一行的多行更新时间视觉居中；
3. 标题、额度值和更新时间的现有水平对齐不变；
4. 官方额度卡片的垂直对齐行为不变；
5. 卡片尺寸、位置、间距和窗口高度不因本次修改改变；
6. 相关自动化测试通过，浅色与深色视觉检查无裁切、重叠或布局跳动。

## 8. 风险控制

| 风险 | 控制措施 |
| --- | --- |
| 条件范围过宽，改变官方卡片 | 仅在 `SourceKind` 严格等于 `Relay` 时应用，并用同次渲染的官方卡片断言回归 |
| 垂直属性误改水平布局 | 不修改 `TextAlignment`、列定义、宽度、边距或文本换行属性，并增加关键水平对齐断言 |
| 隐式样式影响嵌套控件 | 直接设置五个已知文本控件，不添加卡片级隐式样式 |
| 多行文本高度变化产生误判 | 测试夹具显式包含多行辅助说明和多行更新时间，视觉检查覆盖实际行高差异 |
| 覆盖工作树中的现有修改 | 只在目标局部增量编辑，提交时精确暂存本任务文件 |
